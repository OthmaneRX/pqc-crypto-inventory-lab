# pqc-crypto-inventory-lab

Lab personnel : inventaire cryptographique d'un mini-parc conteneurisé
et préparation à la migration post-quantique (ML-KEM, ML-DSA, SLH-DSA, TLS hybride).

🚧 En cours de construction.

> Environnement 100 % local (Docker). Aucun système, scan ou donnée d'entreprise.
> Aucune clé privée n'est versionnée : tout le matériel cryptographique est régénéré par script.
